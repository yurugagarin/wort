reagieren :: re·a·gie·ren (re-a-gi-rın) = REHA + GİRİN | TEPKİ VERMEK | REHA kapıdan GİRİNce koltuğun altındaki dev yay seni havaya fırlatıyor; sen havada bacaklarını çırpıp ani bir TEPKİ VERİYORsun, tavandaki avize kulaklarına çarpıp çınlıyor.
eröffnen :: er·öff·nen (er-öf-nın) = ER + ÖF + NİNE | AÇMAK | ER üniformalı komutan sıcak çorbayı ÖF ÖF diye üfleyip bebeğe NİNE söylerken dev dükkân kapısını AÇIYOR; içeriden yüzlerce balon fışkırıp tavanı dolduruyor.
sich ausbreiten :: aus·brei·ten (aus-bray-tın) = AVUÇ + BRIGHTON | YAYILMAK | Bir AVUÇ tereyağını BRIGHTON plajındaki sıcak ekmeğe sürünce yağ bütün kumsala YAYILIYOR; martılar ekmeğe konup şıpırdayan yağı yalıyor, ayakların kayıyor.
vergrößern :: ver·grö·ßern (fer-grö-san) = FER + GÖRSEN | BÜYÜTMEK | Kuzenin FER, GÖRSEN şaşarsın diye dev bir büyüteçle minik karıncayı fil kadar BÜYÜTÜYOR; karınca hortum gibi ötüp seni bahçede kovalıyor.
sich handeln um :: han·deln um (han-dıln um) = HANDEL + UMUT | SÖZ KONUSU OLMAK | HANDEL'in orgundan çıkan dev UMUT balonunun içinde SÖZ KONUSU OLAN tek şey minik bir kedi; balon kediyle birlikte seni de tavana kaldırıyor.
sich lohnen :: loh·nen (lo-nın) = LONCA | DEĞMEK | LONCA ustasıyla ter içinde yüz basamak tırmanıp tepedeki fırından sıcak baklava aldığında bütün yorgunluk sana DEĞİYOR; ağzında şerbet akıyor, parmakların yapış yapış.
ersetzen :: er·set·zen (er-zet-sın) = ER + SET + SEN | YERİNE KOYMAK | Tenis kortunda ER üniformalı topçu her SET arasında kopan fileyi SEN dev bir pastayla YERİNE KOYUYORsun; pastanın kreması fileye yapışıp toplar kremaya batıyor.
investieren :: in·ves·tie·ren (in-ves-ti-rın) = İN + VESTİYER | YATIRIM YAPMAK | Tiyatro merdivenlerinden İNip VESTİYERdeki bütün paltoları maaşınla satın alarak YATIRIM YAPIYORsun; paltolar kollarını sallayıp seni alkışlıyor.
wegwerfen :: weg·wer·fen (vek-ver-fın) = BEK + VER + FEN | ATMAK | Maçta BEK sana pas VERİNCE sen elindeki FEN kitabını çöp kutusuna ATIYORsun; kitap kutudan sıçrayıp kafana geri dönüyor, sayfalar kanat gibi çırpınıyor.
hinweisen :: hin·wei·sen (hin-vay-zın) = HİN + VAY + ZEN | DİKKAT ÇEKMEK | HİN bir tilki ZEN bahçesinin ortasına dev kırmızı bir ok dikip herkesin DİKKATİNİ ÇEKİYOR; sen ağzın açık "VAY" diye bakarken ok kuyruğunu sallıyor.
